How to use

This tool automatically extracts the main picture from species records on the NBN Atlas (and often works on similar biological record websites).

  1. Find a species page (e.g., https://species.nbnatlas.org/species/NHMSYS0000875564).
  2. Copy the URL from your browser's address bar.
  3. Paste it into the input box on this site and click Extract.

Technical note: This app runs entirely in your browser and uses a secure CORS proxy to fetch external HTML content safely.
